装到桌面 · 三步搞定

方法一（最稳·手机自带浏览器）
用手机自带的浏览器（华为/小米/OPPO/荣耀 浏览器，就是出厂那个）打开本链接 → 点「≡ 或 ⋮」菜单 → 找 添加到主屏幕 / 添加至桌面 → 确认。
方法二（任意浏览器·桌面快捷方式）
回到手机桌面，长按空白处 → 点「窗口小部件 / 添加工具」 → 找到任意浏览器 → 选「网页快捷方式」 → 粘贴本链接 → 添加到桌面。
方法三（扫码换浏览器）
用手机相机扫下面二维码，在能装的浏览器里重复方法一。
装好后桌面出现图标，点开即全屏 App，每天自动更新，不用重装。
